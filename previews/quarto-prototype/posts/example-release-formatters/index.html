Upgrade guide

Code blocks get syntax highlighting and a copy button:

install.packages("formatters")
library(formatters)
format_value(3.14159, "xx.xx")

Tabsets let readers pick the variant that fits them:

  • CRAN
  • GitHub
install.packages("formatters")
pak::pak("insightsengineering/formatters")

A collapsible code block hides the details until needed:

x <- c(1.234, 22.5, 333)
format_value(x, "xx.x")
